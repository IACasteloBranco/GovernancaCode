# Relatórios

Relatórios de QA, evidências de execução e capturas devem ser armazenados aqui.

Use `reports/evidence/` para evidências por rodada. Não inclua tokens, credenciais, dados pessoais reais ou conteúdo de clientes.

O modelo histórico de evidências permanece em `docs/REGISTRO_EVIDENCIAS_POC_v0.1.csv` até a consolidação da nova organização.
