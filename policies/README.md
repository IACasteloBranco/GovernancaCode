# Políticas

Este diretório é o ponto de entrada para políticas aprovadas. Alterações aqui exigem aprovação humana explícita.

A política atualmente usada pela POC ainda está em `docs/politica_bloqueio_prompts_v0_1.md`, pois permanece no estado de trabalho não consolidado do repositório. Antes de mover ou consolidar esse arquivo, alinhar a mudança com o responsável pelo projeto para evitar divergência entre documentação e extensão.

Regra operacional: nem o Codex nem o Work devem alterar uma política apenas para fazer um teste passar. Ambiguidades devem ser registradas como `POLICY-QUESTION`.
