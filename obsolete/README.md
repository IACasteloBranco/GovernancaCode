# Archived versions

Use the root `backend/` and `extension/` directories for the active setup.

This folder preserves older extension packages, the former stream POC backend, and its historical notes. Do not load archived extension folders in Chrome. Unpacked extensions loaded from a new directory receive a different Chrome extension ID and need a new installation registration and collaborator assignment.

## Contents

- `Extensão/`: earlier integrated, network, and legacy extension packages.
- `extension-network-poc-root-compat/`: duplicate compatibility copy of the old network POC.
- `governanca-main/`: former project copy and stream backend. The active stream extension now lives at the repository root.
